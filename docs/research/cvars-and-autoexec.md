# CS2 CVars and autoexec research

This note is a source and scope record, not an instruction to apply every listed setting. CVar names, defaults, and behavior are game-build dependent. Validate against the installed client and current Valve material before using a setting.

The package assets are examples and optional managed CFG inputs. `assets/cfgs/autoexec.cfg.example` is not silently deployed. The normal generated configuration remains a narrowly defined managed output; optional CFG deployment is explicit and verified.

Vendor guidance and community measurements can explain a mechanism, but they do not establish a universal frame-time or latency result. Keep primary game and vendor sources with any proposed change and record counterexamples or uncertainty.
