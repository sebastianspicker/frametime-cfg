# Settings audit

The project distinguishes implemented behavior from claimed benefit. Registry, scheduler, service, cache, network, graphics-driver, and game settings are not portable performance guarantees.

Default Windows behavior, current game settings, vendor documentation, and repeatable measurement take precedence over old tuning lists. A setting should remain advisory, conditional, or excluded when its target cannot be identified, the recovery boundary is weak, or the measured effect is not reproducible on the target system.

The native workflow records typed state and evidence where it can, but source structure does not substitute for Windows hardware results.
