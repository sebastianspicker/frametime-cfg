# Autoexec baseline

`assets/cfgs/autoexec.cfg.example` is a manually reviewed starter asset. It is not an assertion that every command is optimal and it is not automatically written by the core workflow.

Optional CFG assets are packaged under `assets/cfgs/`. Explicit deployment validates the selected CS2 target, captures supported prior bytes, writes only the requested managed files, and verifies their bytes. Runtime execution by the game remains outside that file-level verification boundary.

Compare settings against the installed CS2 build and personal accessibility, display, audio, and network requirements before adoption.
