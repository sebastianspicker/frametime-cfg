# Archive

This directory preserves historical material and is excluded from Driver Foundry runtime and CI.

| Path | Contents |
|------|----------|
| [legacy/](legacy/) | Preserved .NET products, reverse-engineering notes, and reference-only material |
| [ledgers/](ledgers/) | Historical source-to-rewrite parity records and completed legacy refactor ledgers |

Nothing under `archive/legacy/` is a supported executable, dependency, or source of runtime data for the root-level Rust workspace. Proprietary reference binaries remain excluded and must not be redistributed.

The ledgers retain legacy product names where they identify the original comparison source. Current implementation names, commands, and environment variables use the Driver Foundry namespace.
